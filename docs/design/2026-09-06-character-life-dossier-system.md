# 小说人物全生命周期深度解构系统设计文档

## 1. 目标与愿景
构建代码算法与大模型深度协同的小说人物深度解构系统：
- **生平经历与时序生命线**：以章节为轴，精准梳理人物从登场、冲突、抉择到蜕变的生平大事件；
- **装备道具与物品追踪**：精准定位人物持有的关键物品、道具、法宝、武器，追踪其获得、使用与转手状态；
- **情感与心理弧光演变**：量化人物在各章节情境下的心理状态与人际情感羁绊演化；
- **多维度评分模型**：代码计算心智、战力/危险度、剧情影响力等量化评分并定级；
- **记忆向量检索库（Memory Vector Store）**：实现基于人物切片的混合记忆检索（代码精确实体约束 + 语义向量余弦相似度）；
- **LLM 全景画像生成**：通过紧凑且极度准确的代码数据包赋能大模型，快速生成人物全生命周期深度剖析报告，消除幻觉并降低 Token 花销。

---

## 2. 模块划分与算法设计

### 2.1 装备道具与物品追踪器 (`ItemTrackerService`)
- **物品模式挖掘**：
  - 武器/装备类（“枪”、“子弹”、“炸药”、“刀”、“剑”、“匕首”、“护甲”等）；
  - 特殊道具/灵异/修真法宝类（“面具”、“保险柜”、“电脑”、“鬼眼”、“皮夹”、“黄金盒”、“灵异物品”等）；
  - 动作动词绑定：匹配“获得”、“捡起”、“拿出”、“买下”、“夺取”、“使用”、“交给”、“扔掉”、“摧毁”等操作动词。
- **所有权与状态机**：
  - 实体关联：将物品与当前持有角色绑定；
  - 状态流转：`acquired`（获得）、`used`（使用）、`transferred`（转移）、`lost`（遗失/损坏）。

### 2.2 情感演化与心理弧光检测器 (`EmotionalArcService`)
- **多维情感词典加权**：
  - 积极/自信（从容、冷静、自信、微笑、欣喜）；
  - 紧张/危机（震惊、警惕、心跳加速、冷汗、恐惧）；
  - 愤怒/反抗（狂怒、杀气、冷冽、死战、咆哮）；
  - 绝望/痛苦（崩溃、惨叫、无力、绝望、苍白）。
- **心理张力与弧光跟踪**：
  - 按章节生成角色心理状态轨迹（Mood Score: -1.0 极度负面/恐惧 到 +1.0 极度从容/自信）；
  - 识别性格转折点（Turning Points）。

### 2.3 多维能力与影响力评分模型 (`CharacterScoringService`)
- **评分维度**：
  - **心智/谋略评分 (Mental Score: 0-100)**：基于分析、解谜、推理动词与从容度加权；
  - **危险/战力评分 (Power Score: 0-100)**：基于战斗、杀伐、致命道具与冲突参与度；
  - **剧情支配力 (Plot Impact: 0-100)**：基于跨章节出场频次、中心度与共现连接数；
  - **综合评级 (Overall Tier)**：S 级（绝顶主角/幕后主使）、A 级（核心巨头/主力搭档）、B 级（重要干将）、C 级（功能配角）。

### 2.4 人物记忆向量检索库 (`CharacterMemoryVectorStore`)
- **记忆切片（Memory Slices）**：
  - 将角色登场、关键交互与转折场景切片存储为带有实体元数据的向量记录；
- **混合检索（Hybrid Retrieval）**：
  - 第一层：通过角色实体名称与别名快速代码过滤对应章节记忆；
  - 第二层：基于查询文本特征与语义向量余弦相似度重排，毫秒级定位最相关的人生记忆片段。

### 2.5 全景人物档案聚合与 LLM 画像生成 (`CharacterDossierService`)
- **档案卡聚合**：合并生平经历、物品清单、情感轨迹、多维评分与高光记忆；
- **LLM 深析提示词优化**：将原本分散的数十万字小说精炼为 2,000 字的高密人物档案卡，供大模型一键输出深度的人物生平经历、心理弧光与命运结局剖析。

## 3. 验收标准
1. **算法与实体提取准确**：在《天才俱乐部》中准确扒出“林弦”的生平循环、获得的物品道具（奥特曼面具、C4炸药、手枪、保险柜）、情感心理轨迹（从童年恐惧到成年享受循环再到探寻真相）、多维评分达到 S 级。
2. **在《神秘复苏》中准确扒出**：“杨间”的生平开端（大昌七中）、获得的核心灵异道具/状态（鬼眼、鬼影）、心理从恐惧到冷静果断的蜕变、S 级评级。
3. **向量检索可用**：支持通过语义（如“银行仓库破解密码”或“教室敲门鬼袭击”）毫秒级召回对应人物记忆切片。
4. **全量 TDD 测试保证**：新增测试覆盖物品追踪、情感弧光、评分模型与混合检索，全量测试保持 100% 通过。
