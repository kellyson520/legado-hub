# Frontend Bilingual Localization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every fixed user-visible console string available in Chinese and English, default to Chinese, and persist a user-selected language without changing API or business data.

**Architecture:** Add a small React `LanguageProvider` backed by typed catalogs and a `useLanguage` hook. The root app provides the language context; shared shell/components and feature pages request translated strings through stable keys. Unknown server values remain unchanged, while known statuses, roles, and error codes use locale-aware maps.

**Tech Stack:** React 18, TypeScript, Vitest, Testing Library, Vite, localStorage.
