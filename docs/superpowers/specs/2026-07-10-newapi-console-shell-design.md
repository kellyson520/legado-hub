# New API 风格控制台壳层设计

## 目标

将现有管理前端统一为紧凑的运维控制台，采用左侧导航和顶部工具栏。保留当前 API、登录、刷新令牌、权限守卫以及路由行为，不改变业务功能。

## 范围

- 提供桌面侧边栏、移动端导航抽屉和顶部控制栏。
- 支持浅色、深色与跟随系统三种主题；用户选择保存到 `localStorage`。
- 侧边栏按资源、运营、管理分组，并根据现有 permission 隐藏无权限入口。
- 统一页面内容容器、标题区、操作区、表格和状态元素的密度、边框及颜色 token。
- 顶部显示当前位置、服务状态、主题切换和账户菜单，账户菜单提供退出操作。

## 信息架构

资源组包含书源、健康诊断；运营组包含规则引擎、AI 任务、翻译任务、小说任务；管理组包含用户、审计、系统设置。导航的显示权限与 `router.tsx` 的守卫权限一一对应。用户直接访问受限路由时，仍使用既有 `RequirePermission` 拦截。

## 视觉与交互

界面参考 New API 的简洁操作台信息密度，但不复制其品牌资产或布局细节。采用石墨中性色作为深色基底、灰白作为浅色基底、青绿色作为主操作色、蓝色作为信息状态、琥珀色和红色分别表示警告与失败。组件圆角不大于 8px，表格和工具按钮维持稳定尺寸。

桌面端侧边栏宽 248px，可折叠为图标栏；移动端侧边栏通过顶部菜单按钮打开。主题控件提供“浅色 / 深色 / 系统”三个模式。用户切换主题后立即写入持久化设置；系统模式监听系统配色变化。

## 组件边界

- `ConsoleLayout`：导航、顶部栏、页面内容插槽、主题和移动端导航状态。
- `ThemeProvider`：解析并保存主题模式，为根节点挂载主题属性。
- `navigation` 配置：路由、图标、权限与分组的单一数据源。
- 业务页面：继续拥有自己的数据加载、筛选和操作，只接收统一的内容容器样式。

## 验收与测试

- 登录后能通过侧边栏前往所有当前可访问页面，活动项随路由变化。
- 无权限的导航项不可见，受限 URL 仍无法访问。
- 浅色、深色、系统主题可切换并在刷新后保留；系统模式响应系统偏好变更。
- 侧边栏在窄屏下可打开和关闭，导航选择后关闭。
- 现有登录、路由守卫和业务页面测试继续通过；新增布局与主题测试覆盖上述行为。
